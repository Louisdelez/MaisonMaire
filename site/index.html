Features

Everything you need,
nothing you don't

Built with simplicity in mind. No frameworks, no build tools, no server required.

Service Dashboard

Centralize all your self-hosted services, projects, and bookmarks in a modern responsive interface.

Authentication

Built-in login and registration system to keep your dashboard private and secure.

Admin Panel

Full CRUD operations with icon picker, color picker, and category management for your services.

Theme System

Dark, Light, and System theme modes. Your dashboard adapts to your preference automatically.

5 Languages

Fully translated in French, English, German, Italian, and Spanish with beautiful SVG flag icons.

Export / Import

Export your entire configuration as JSON and import it anywhere. Your data, your control.

Getting Started

Up and running in seconds

Clone the repo, open the file, and you're done. It's that simple.

1

Clone

Clone the repository from GitHub to your local machine or server.

2

Open

Open index.html in your browser. No server setup needed.

3

Customize

Add your services, pick your theme and language, and make it yours.

# Clone the repository $ git clone https://github.com/Louisdelez/MaisonMaire.git   # Open in your browser $ cd MaisonMaire && open index.html   # Or serve it (optional) $ python3 -m http.server 8080
